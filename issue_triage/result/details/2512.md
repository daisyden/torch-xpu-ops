floating point input does not have a deterministic implementation' but the XPU op raises
'alertNotDeterministic("_histc_xpu")' (no '_with floating point input' suffix). See
third_party/torch-xpu-ops/src/ATen/native/xpu/SummaryOps.cpp:45. The upstream test message regex
(CUDA equivalent) was updated to include the suffix; XPU side did not match. PR #3333 already filed.
