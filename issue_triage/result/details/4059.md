## Root Cause

Release-over-release compiler-path regression: 99 E2E cases slower only on Inductor while eager is
mostly stable, so the slowdown is primarily in PT2.13 Inductor codegen/scheduling, not
model/operator baselines. Breadth (99 models, mostly training) indicates systemic regressions
(fusion decisions, autotune/heuristic shifts, kernel selection) across common training patterns.
Main dependency upstream Inductor, Triton a possible sub-component.
