## Root Cause

Enhancement to switch the kernel-specific max-work-group-size query in
third_party/torch-xpu-ops/src/comm/DeviceProperties.h:14-28 to the recommended SYCL shortcut API
introduced by intel/llvm PR #15650. The dependency is blocked on oneAPI compiler issue
CMPLRLLVM-71252 (performance regression), and per the latest comment the fix will land in oneAPI DLE
26.0. No functional bug; purely an API-modernization task.

## Fix Approach

- - - - Once oneAPI 2026.0 DLE is the minimum supported toolchain, replace the manual ext_oneapi_get_kernel_info path in src/comm/DeviceProperties.h:14-28 with the new sycl::ext::oneapi::experimental::info::kernel::max_work_group_size shortcut and remove the workaround. - Gate with __SYCL_COMPILER_VERSION until the floor moves.
