## Root Cause

Random CI failure of test_foreach_copy_with_multi_dtypes_large_input_xpu (40GB tensor of 2**31+1
fp32 + bfloat16 src) manifests as UR_RESULT_ERROR_OUT_OF_RESOURCES or pytest-xdist worker aborts.
The test passes locally on PVC and skips on BMG with insufficient memory; under multi-worker xdist
on shared CI runners, concurrent allocations exhaust device memory in the foreach_copy SYCL path
(third_party/torch-xpu-ops/src/ATen/native/xpu/sycl/ForeachCopyKernels.cpp). Likely combined with L0
memory management / ZE_AFFINITY_MASK CI infra issue (#2966, #3326).
