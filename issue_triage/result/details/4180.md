## Root Cause

The failing upstream UT variants call linalg.lu_factor with pivot=False on XPU, but that path falls
back to CPU, which doesn't implement LU without pivoting, so the fallback throws RuntimeError
instead of executing on XPU. Matches earlier recurrences (#3833/#4013); a functional gap, not a new
crash. The fix is the XPU pivot=False lu_factor via oneMKL getrfnp tracked in #3951. (In NA sheet as
not_target.)

- keep this blocked on #3951 until fully integrated.
