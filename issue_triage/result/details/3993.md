validation shows a transformers patched wheel (huggingface/transformers PR #45936) restores
performance for essentially all listed models, indicating the dominant cause is transformers v5
model-stack changes interacting with PT2.13 Inductor paths on Windows XPU, not a broad XPU
driver/Triton regression. Residual beit_base_patch16_224 split to tracker #4051.
