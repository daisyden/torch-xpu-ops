## Root Cause

aten::_flash_attention_forward is declared CUDA-only in native_functions.yaml:15284-15288, so no XPU
kernel is registered. XPU flash-attention code exists
(third_party/torch-xpu-ops/src/ATen/native/transformers/xpu/flash_attn/flash_api.cpp:25-145) but is
not wired into ATen dispatch for this op. Only _scaled_dot_product_flash_attention is registered for
XPU (native_functions.yaml:15215-15218, impl xpu/attention.cpp:18-53).

## Fix Approach

- Add XPU dispatch registration for aten::_flash_attention_forward in native_functions.yaml and provide an at::native XPU kernel entry point (wrapper if needed) delegating to the existing XPU flash-attn implementation, keeping signatures aligned with the schema.
- Add/enable a targeted XPU meta-dispatch test for torch.ops.aten._flash_attention_forward float16 to verify the gap is closed.
