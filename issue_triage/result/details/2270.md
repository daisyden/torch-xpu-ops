## Root Cause

test_comprehensive_torch_ops_aten__flash_attention_forward_xpu_float16 in test_decomp_xpu fails with
backend compatibility error because the decomposition cross-ref dispatches _flash_attention_forward
to CPU where it is not registered (XPU-only op). Same root cause family as #2285:
aten::_flash_attention_forward only has XPU/Meta keys. Tracking PR #2262.

## Fix Approach

- - - - Add the test to skip_list for test_decomp_xpu (decomp cross-ref doesn't make sense for backend-private flash attention ops), or register a Meta/CompositeImplicitAutograd decomposition for _flash_attention_forward upstream. - Resolve once #2262 lands.
