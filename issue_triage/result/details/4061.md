## Root Cause

PT2E INT8 perf on BMG Linux: 8 new failures (valid baseline throughput, now fail) due to torchao
prepare() rejecting XPU - 'AssertionError: prepare only works with cpu or single-device CUDA
modules, but got devices {device(type=xpu)}'. The torchao/PT2E prepare device check does not allow
XPU single-device modules.

## Fix Approach

- Patch the torchao/PT2E prepare() device assertion (in torchao or upstream pytorch quant) to accept single-device XPU modules alongside CPU/CUDA.
- verify the INT8 prepare->convert flow on XPU.
- Add a regression exercising PT2E INT8 prepare on an XPU module.
- backport to release/2.13 once landed. (Placeholder triage.
