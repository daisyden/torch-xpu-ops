## Root Cause

test_fd_sharing exercises fd-based tensor sharing in multiprocessing, relying on file-descriptor
passing semantics generally unavailable on Windows. On Windows XPU (Arc B580) the fd_sharing
assertion fails consistent with the platform limitation. This is a platform-support mismatch in test
expectations, not a high-severity runtime regression.

## Fix Approach

- Conditionally skip test_fd_sharing (or the fd-sharing branch) on Windows for XPU in test_multiprocessing_xpu.py, routing Windows coverage to supported IPC/share-memory strategies.
- Align skip logic with upstream PyTorch multiprocessing platform guards and document fd-sharing as unsupported on Windows.
