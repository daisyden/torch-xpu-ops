## Root Cause

The live issue aggregates more than six migrated UT failures, with the maintainer noting that the
_flash_attention_forward cases are waiting for flash attention implementation.
src/ATen/native/xpu/XPUFallback.template:226-256 registers CPU fallback for
_efficient_attention_forward at line 232 but omits _flash_attention_forward, while
yaml/native/native_functions.yaml:7300-7310 only covers quantized empty factory registrations and
not the missing QuantizedXPU accessors such as q_scale/empty_quantized, so several skipped tests
fail from missing backend coverage rather than a test assertion bug.

## Fix Approach

- Split the migrated failures by owner: add a real XPU _flash_attention_forward implementation or register a temporary CPU fallback for it until the flash path is ready, and separately complete or gate the deprecated QuantizedXPU operator set.
- Keep test_view_ops_xpu ravel/flatten skips tied to the quantized deprecation note, then remove the batch skips only after each backend registration has targeted tests.
