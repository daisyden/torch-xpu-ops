## Root Cause

8.37% training latency regression (22.044ms -> 23.889ms) for mobilenet_v3_large with Inductor on
Windows Arc B580, while eager is good - compiler-path overhead, not a base XPU kernel regression.
Linux does not reproduce, narrowing this to a Windows-specific PT2.13 compiler-stack regression.
Appears only in the Inductor path across 2.12->2.13, so most likely upstream Inductor changes
(possibly interacting with backend codegen/runtime on Windows). >7% -> P0.
