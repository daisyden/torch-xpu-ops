## Root Cause

test/distributed/test_c10d_logger.py expects dist.broadcast(tensor, self.world_size + 1) to raise at
lines 71-87 so _exception_logger can log the error. The Python broadcast wrapper canonicalizes the
root at torch/distributed/distributed_c10d.py lines 3113-3123, but get_group_rank returns the global
rank unchanged for the default WORLD group at lines 1124-1125, so the invalid root reaches
ProcessGroupXCCL::broadcast; the XCCL implementation computes opts.rootRank + opts.rootTensor and
calls onecclBroadcast without validating the root range at src/xccl/ProcessGroupXCCL.cpp lines
1436-1483, so no Python-visible exception is raised in this test.

## Fix Approach

- - - Add root-rank validation for XCCL broadcast before launching oneCCL, either in ProcessGroupXCCL::broadcast or in the shared distributed rank canonicalization path so WORLD also rejects roots outside [0, world_size). - The minimal torch-xpu-ops fix is to TORCH_CHECK root >= 0 && root < getSize() in src/xccl/ProcessGroupXCCL.cpp before collective(), then rerun test_c10d_logger.py::C10dErrorLoggerTest::test_exception_logger.
