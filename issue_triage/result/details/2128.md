commit) = compatibility skew. The 2.9-pinned path fails earlier with an fbgemm_gpu_py.so load error
on Windows, indicating benchmark/dependency packaging issues in the upstream torchbench stack. The
0xC0000005 crash occurs in generated native code during training/backward, but evidence is
insufficient to attribute directly to driver or Triton without removing the env mismatch.
