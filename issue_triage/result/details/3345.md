## Root Cause

Infrastructure/CI request, not a bug. Copilot cloud agents have no XPU device, so they cannot run
torch-xpu-ops validation during PR generation. The author proposes adding
.github/workflows/copilot-setup-steps.yml that targets the existing pvc_rolling self-hosted label so
the Copilot environment can source oneAPI, install build deps, and run XPU tests before submitting
PRs.
