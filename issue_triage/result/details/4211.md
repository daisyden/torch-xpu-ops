## Root Cause

#4211 is an umbrella regression tracker containing multiple independent failures rather than one
runtime defect. The main concrete regressions are test-port drift in XPU mirrors: stale dynamo
attribute hooks
(`third_party/torch-xpu-ops/test/xpu/dynamo/test_misc_xpu.py:12735-12753,13137-13157`) and stale
cond exception expectation (`third_party/torch-xpu-ops/test/xpu/test_linalg_xpu.py:709-712`), plus
separate decomp/foreach behavior gaps tracked in split issues. The issue’s own comments already
group these into sub-issues, confirming mixed root causes and mixed ownership.

## Fix Approach

- Keep #4211 as a tracker only: land fixes via split issues (#4218/#4217/#4216/#4213 and remaining custom-op/profiler items), then close the umbrella after child verification.
- Add an automated upstream-sync check for high-churn mirrored tests (`test_misc`, `test_linalg`, `test_decomp`, `test_foreach`) to prevent future batch regressions.
