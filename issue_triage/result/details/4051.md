## Root Cause

Regression isolated to PT2 Inductor on Windows XPU for beit_base_patch16_224 (eager healthy),
pointing to a compiler/codegen path change. PT2.12->PT2.13 latency deltas ~19-25% exceed the 7%
threshold, though Linux retests don't reproduce (platform-specific). Residual after #3993 and
unchanged by the transformers-changed run indicate it's not primarily transformers-side. Most
plausible: a Windows-specific Inductor scheduling/cache/codegen regression in the 2.13 stack.
