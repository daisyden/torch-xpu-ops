## Root Cause

index_select is implemented as an XPU operator in yaml/xpu_functions.yaml lines 108-109 and
dispatched through src/ATen/native/xpu/Indexing.cpp lines 31-53 into xpu::index_select_kernel. The
SYCL implementation in src/ATen/native/xpu/sycl/Indexing.cpp lines 201-238 always uses the generic
IndexKernel path, only toggling trivial offset calculation for contiguous output/index at lines
215-230; unlike CUDA's specialized gather paths, it also forces src.contiguous() at lines 205-209
and has no embedding/index_select fast path for dim=0 contiguous tables.

## Fix Approach

- - - - Add a specialized contiguous dim-0 index_select/embedding gather path in src/ATen/native/xpu/sycl/Indexing.cpp, with a vectorized row-copy kernel for common embedding shapes and a separate handling path for non-contiguous indices that avoids unnecessary full generic indexing overhead. - Keep the generic IndexKernel fallback for uncommon strides/dimensions and add microbench/regression coverage for contiguous and as_strided index tensors.
