## Root Cause

Failure in multiprocessing tensor inheritance on Windows, where spawn-based IPC semantics differ
from fork and are more sensitive to backend shared-memory handling. For XPU tensors, the inherited
storage is likely not synchronized/reconstructed identically in the child process, producing value
mismatches at assertion. Single core-path UT failure -> P2.

- Reproduce on Windows Arc B580 with verbose multiprocessing diagnostics.

- align with upstream multiprocessing contracts.
- If the defect is core runtime IPC, file/track an upstream fix and temporarily gate/xfail on affected Windows XPU configs.
