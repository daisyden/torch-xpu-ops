## Root Cause

The XPU fast-path kernel for foreach copy omits float8 scalar types from dtype dispatch. In
third_party/torch-xpu-ops/src/ATen/native/xpu/sycl/ForeachCopyKernels.cpp, foreach_copy_list_kernel_
uses AT_DISPATCH_ALL_TYPES_AND_COMPLEX_AND3(Half, BFloat16, Bool), so Float8_e4m3fn etc. are
excluded and trigger 'not implemented'. TorchAO fp8 flows hit this via _foreach_copy_ and fail,
though CUDA already dispatches float8.

## Fix Approach

- Update the XPU foreach-copy dtype dispatch to include standard float8 dtypes (Float8_e4m3fn, e4m3fnuz, e5m2, e5m2fnuz) for src+dst, mirroring CUDA foreach_tensor_copy.
- add an XPU regression calling _foreach_copy_ with float8 tensors in TorchAO-like usage.
