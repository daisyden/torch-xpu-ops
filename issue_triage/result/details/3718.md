## Root Cause

The attached Windows build log shows Build Tools 18.6/MSVC 19.51 and oneAPI DPC++ 2025.3.2 are
selected, with SYCL discovered by cmake/Modules/FindSYCLToolkit.cmake:36 and wired into XPU builds
by cmake/public/xpu.cmake:11. Configuration later fails while building compiler feature probes
before torch-xpu-ops finishes, so this is a Windows toolchain compatibility/regression issue rather
than an individual XPU operator failure; torch-xpu-ops only contributes the Windows SYCL library
split at third_party/torch-xpu-ops/src/BuildOnWindows.cmake:44.

## Fix Approach

- - Reduce the failure to the first failing CMake try-compile/Ninja command from CMakeFiles logs under Build Tools 18.6, then add a CMake/toolchain workaround or version gate if PyTorch flags are incompatible with MSVC 19.51/oneAPI 2025.3.2. - Validate by rebuilding on Windows with both 18.4 and 18.6 and documenting any required Build Tools pin if the root cause is an upstream compiler regression.
