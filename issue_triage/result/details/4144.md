## Root Cause

Regression in the compiled training path: timm cait_m36_384 bf16 on PVC previously fit but now OOMs
on latest PyTorch. Pattern points to increased peak memory from recent Inductor
scheduling/buffering/planning changes, not a model change. In E2E training, extra live intermediates
or reduced buffer reuse in generated graphs can raise peak allocation past device limits, turning a
passing run into OOM.
