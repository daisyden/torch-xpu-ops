## Root Cause

XPU SYCL kernels have partial bcomplex32 enablement: only a subset of operators updated dispatch
macros to include kBComplex32, while many kernels that already support kComplexHalf omit it. Type
promotion from bfloat16 tensors with complex scalars can produce torch.bcomplex32, so missing
dispatch entries surface as NotImplementedError on XPU even when CUDA supports the path.
Cross-cutting and mechanical across many operator families, not a single algorithmic defect.

## Fix Approach

- Systematically add kBComplex32 alongside kComplexHalf at all listed XPU dispatch sites (CUDA parity pattern), prioritizing core ops first, landing in small reviewable PRs per priority group.
- Per batch, run build/UT coverage plus targeted promotion tests (bfloat16 + complex scalar -> bcomplex32) and explicit dtype=torch.bcomplex32 operator checks.
- ensure CPU-XPU comparison handles bcomplex32 casting consistently.
