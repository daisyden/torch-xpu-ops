## Root Cause

third_party/torch-xpu-ops/src/ATen/native/xpu/TensorShape.cpp:58 dispatches aten::cat to the XPU cat
kernel, and third_party/torch-xpu-ops/src/ATen/native/xpu/sycl/Shape.cpp:568 implements the
multi-input copy path. The issue's roofline data shows cat is underutilizing memory bandwidth across
54 eager OOB models, so the bottleneck is the generic SYCL batched-copy implementation and its
launch/vectorization choices rather than a missing dispatch.

## Fix Approach

- Optimize the Shape.cpp cat kernel for the OOB fp16 cases: add profiling-driven fast paths for contiguous same-dtype inputs, improve vectorized load/store coverage and launch geometry, and add targeted microbenchmarks/model traces to guard B580/G31 roofline efficiency regressions.
