## Root Cause

torch/_inductor/fx_passes/fuse_attention.py:1327 is where Inductor registers SDPA graph-pattern
replacements, but the issue reports 25 torch.compile inference models still lower to
BMM+Softmax+BMM. The existing serialized/pattern list in this upstream PyTorch pass does not match
those model attention graphs, so no aten.scaled_dot_product_attention node is produced for backend
fusion.
